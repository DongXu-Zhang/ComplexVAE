# 白点问题：v2.1 改的是「损失怎么用」，不是再加一项、也不是整项关掉

## 你说得对的地方

不能靠再加一项损失去堵黑色。灰色、深色平坦区会出同样的事。  
也不能把 amp_norm / 边缘 / 高频整项关掉：那是 v2 用来对齐三源幅度、保住细丝的东西。  
第一版（f8/z4，100k）没有这类噪点，所以是 **v2 中间新加的用法** 把问题引进来的。

## 中间到底加了什么

1. **amp_norm**：空块/低对比块用很小的 `s` 去除，误差最多约 20 倍。  
2. **edge 无上限**：平坦里一个尖点，权重可以到十几。  
3. **高频**：尖点在高通里还是尖点。  

再加上 f4 每个格子 4×4 像素，拟合出来就是小白块。

只按整张 256 crop 开关也不够：有细胞、背景很大的图，范围够大，整张仍会开 edge/HF，白点正好出在那片背景上。

## 现在的正式配方

**`configs/experiment/s1_hq_f4z4_v2_1.yaml`**

一条规则：**梯度在 9×9 邻域里够密，才算结构。**

- 细丝、颗粒：继续 amp_norm（下限 0.20）、边缘权（封顶 3）、高频 0.05、Scharr。  
- 孤立尖点（黑底、灰底一样）：不放大、不加边缘/高频。像素项仍在，和 v1 一样。  
- 空块：像素项 ×0.25；裁剪太空最多再抽 8 次。  
- **`w_dark_fp = 0`**，不多加暗区专用损失。  
- 网络仍是 f4 + bilinear，没有转置卷积，没有 GAN。

必须重新训练。

## 服务器

```bash
git pull
python -m microscopy_vae.cli train \
  --config configs/experiment/s1_hq_f4z4_v2_1.yaml \

  --override experiment.output_dir=.../s1_hq_f4z4_v2_1_seed0
```
